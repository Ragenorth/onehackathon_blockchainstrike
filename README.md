## ✨ Features

### 🎮 Core Gameplay
- **60-second survival challenge** - Fast-paced arcade action
- **Smooth controls** - Arrow keys to move, spacebar to shoot
- **Real-time scoring** - Earn points by destroying enemies
- **Pause system** - Press ESC to pause/resume

### 🎨 Random Skin System
- **Earn skins every game** - Get random cosmetic after each match
- **Infinite variety** - 2,160,000+ unique skin combinations
- **4 Rarity tiers** - Common, Rare, Epic, Legendary
- **Trading economy** - Sell skins for SUI or equip them

### 💰 Web3 Integration
- **ONEChain Wallet support** - Seamless wallet connection
- **Automatic connection** - Connects when accessing shop
- **Demo balance system** - Shows Web3 economy without real costs
- **Sui blockchain ready** - Smart contracts deployed on testnet

### 🛒 Cosmetic Shop
- **Buy premium skins** - Spend SUI on exclusive cosmetics
- **Manage inventory** - View, equip, and sell your skins
- **Real-time balance** - See your SUI balance in shop
- **Scrollable interface** - Clean, modern design

## 🚀 Quick Start

### Prerequisites
- Node.js 16+ installed
- ONEChain Wallet browser extension (optional)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Ragenorth/onehackathon_blockchainstrike.git
   cd onehackathon_blockchainstrike
   ```

2. **Install dependencies**
   ```bash
   cd frontend
   npm install
   ```

3. **Start the game**
   ```bash
   npm start
   ```

4. **Open in browser**
   - Game runs at: http://localhost:3000

## 🎮 How to Play

### Controls
- **← →** Arrow keys to move left/right
- **SPACE** to shoot
- **ESC** to pause game or exit shop

### Gameplay Loop
1. **Start Game** - Survive 60 seconds
2. **Earn Skin** - Get random cosmetic reward
3. **Visit Shop** - Manage inventory and buy skins
4. **Equip or Sell** - Use skins in game or sell for SUI
5. **Repeat** - Build your collection!
