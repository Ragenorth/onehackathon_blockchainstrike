## 🎥 Recording Tips

### **Technical Setup**
- **Screen Recording:** Use OBS Studio, Loom, or built-in screen recorder
- **Audio:** Clear microphone, quiet environment
- **Resolution:** 1080p (1920x1080) minimum
- **Frame Rate:** 30fps minimum

### **Preparation Checklist**
- [ ] Game is working and tested
- [ ] ONEChain Wallet is installed and set up
- [ ] Sui CLI is configured and working
- [ ] Browser bookmarks ready (Sui Explorer)
- [ ] Script practiced and timed
- [ ] Recording software tested

### **During Recording**
- Speak clearly and at moderate pace
- Keep mouse movements smooth
- Pause briefly between sections
- Show each step clearly
- Don't rush through important parts

### **Content Guidelines**
- Focus on functionality, not code
- Highlight OneWallet integration prominently
- Show real blockchain transactions
- Keep technical jargon minimal
- Emphasize user experience

### **Common Mistakes to Avoid**
- Don't show errors or failed attempts
- Don't spend too long on setup
- Don't forget to show wallet connection
- Don't skip blockchain verification
- Don't exceed 3-minute limit
