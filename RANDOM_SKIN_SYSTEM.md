# 🎨 Random Skin Generation & Trading System

## 🎁 New Features

Your game now has a complete **loot box economy** with randomly generated skins!

## 🎮 How It Works

### **1. Play Game → Earn Random Skin**
```
Play Game (60 seconds)
↓
Game Over
↓
🎁 NEW SKIN UNLOCKED!
- Random rarity (Common/Rare/Epic/Legendary)
- Random colors and patterns
- Random value (0.05-0.8 SUI)
- Unique design every time
```

### **2. Manage Inventory**
```
Go to Shop
↓
🎒 Your Inventory (X skins)
- View all earned skins
- Equip skins for gameplay
- Sell skins for SUI
```

### **3. Sell or Equip**
```
Each Skin:
[🎨 EQUIP] - Use in game
[💵 SELL] - Get SUI value
```
